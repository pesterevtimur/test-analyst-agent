# wikis/

Папка с доменными LLM-wiki. Каждая поддиректория — один домен знаний.

## Что сюда кладётся

Каждый домен — это:

```
<domain>/
├── CLAUDE.md          ← schema именно этой wiki (как ингестить, как запрашивать)
├── index.md           ← иерархический оглавление
├── log.md             ← хронология ingest/query/lint
├── entities/          ← entity-страницы
├── concepts/          ← concept-страницы
├── sources/           ← по странице на каждый raw-источник
├── contradictions/    ← зафиксированные разногласия
├── data/
│   └── tables/        ← структурированные данные из raw (никогда не пересказываются)
└── raw/               ← immutable источники этой wiki
```

## Как сюда что-то попадает

**Только через wiki-skills** (`wiki-llm-builder` для создания, `wiki-ingest` для пополнения). Это правило №2 проекта.

Никакого ручного редактирования entity/concept-страниц. Никакого редактирования `raw/`.

## Домены этого проекта

Заводятся по мере надобности через `wiki-llm-builder`. Кандидаты под тестовое задание:

- `oracle-sh/` — схема Sales History: смысл таблиц и полей, ловушки, типовые запросы
- `openclaw/` — среда выполнения агента: конфигурация, подключение MCP, панель
- `observability/` — Langfuse: трассы, наборы данных, судья

Смысл в том, что бриф (раздел 0, правило 4) требует читать свежие доки через веб, а не по памяти. Wiki с citations делает это требование проверяемым: у каждого факта видно, из какого источника и какой редакции он взят.
