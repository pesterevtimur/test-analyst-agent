# ADR-007. Лишняя строка в ответе это ошибка

Статус: принято. Дата: 3 сентября 2026.

## Контекст

Сравнение идёт по результату (ADR-001) в мягком режиме: порядок строк не важен, лишние колонки не ошибка, числа с допуском 0,5%. Мягкость нужна, чтобы не штрафовать за форму.

Остаётся вопрос: считать ли ошибкой строку, которой в эталоне нет. Обычный мягкий режим на такое смотрит сквозь пальцы, особенно если совпавшие строки совпали точно.

## Решение

Лишняя строка это ошибка, наравне с недостающей. Повтор ключа тоже ошибка.

Причина в том, откуда лишние строки берутся. Их источник один: фильтр, который не сработал. Забыт мандант, забыт признак удаления, забыт язык в таблице текстов, забыт фильтр периода. Значит, в ответе бизнесу лежат чужие данные, и лежат незаметно: суммы по совпавшим строкам сходятся, а итог больше.

Для отчётности это хуже, чем недобор. Недобор виден: цифра меньше привычной, и человек переспрашивает. Перебор выглядит как рост.

Повтор ключа выделен отдельно, потому что так выглядит задвоенное соединение. Соединение позиций фактуры с калькуляцией только по материалу даёт ровно эту картину, и без отдельной проверки задвоение размазывается по строкам и читается как расхождение округления.

## Альтернативы

**Считать только пересечение строк.** Отклонено: превращает пропущенный фильтр в успех.

**Штрафовать лишние строки мягче, отдельной метрикой.** Отклонено на этом объёме: две метрики вместо одной усложняют отчёт ради случая, которого в наборе нет. Если появится класс вопросов, где перебор допустим, решение пересматривается новым ADR.

## Последствия

Хорошее: главная ошибка этой предметной области ловится сравнением, а не глазами. Ограничитель ожидаемых фильтров и это правило смотрят на одну и ту же ошибку с разных сторон: первый предупреждает до выполнения, второе ловит после.

Плохое: набор становится строже к формулировке вопроса. Если вопрос допускает два толкования границ выборки, эталон обязан назвать своё, иначе честный ответ не совпадёт. Отсюда шесть ловушек в наборе: там, где толкований два, правильный ответ это уточняющий вопрос, а не выбор одного из них.
