# harness/tools/lint/

Вспомогательные скрипты для `wiki-lint` skill.

Skill `wiki-lint` будет вызывать эти скрипты для детерминированных проверок (всё, что можно проверить regex'ом или AST-парсингом markdown, лучше делать кодом, а не LLM-grader'ом).

## Запланированные скрипты (пока не написаны)

- `check-citations.py`: проверка citation-coverage (каждое фактическое предложение имеет `^[src:...]`).
- `check-orphans.py`: поиск страниц без входящих `[[ссылок]]`.
- `check-stale.py`: поиск страниц с устаревшей edition raw-источника.
- `check-tables.py`: поиск раздела, похожего на пересказ таблицы (анти-паттерны).

См. `harness/architecture.md`, раздел 6, полный список lint-контрактов.
